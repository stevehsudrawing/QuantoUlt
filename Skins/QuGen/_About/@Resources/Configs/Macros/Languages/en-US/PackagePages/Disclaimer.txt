**Quanto Series** (includes Quanto Original, Quanto Flx, Quanto Ult) is inspired by Fluent Design System and Windows user interface. The project is not using any code from Windows 11. Some of the graphics come from Fluent System Icons, and some are created from scratch to resemble the ones of Windows 11. Any resemblances to existing or future Microsoft(R) products are for customization purposes only, but also with an intention to raise awareness of the mentioned products within the community.

Quanto Ult is a non-profit product that is free forever and does not coerce users to pay. Any donation is voluntary.

Quanto Ult provides "Package" functionality. We cannot guarantee the security of package because there are many sources of it. Package creators are requested to follow the Quanto Ult Package Design Specifications (aka QFPDS).

As tools that does not rely on network services, Quanto Ult's global settings, skin settings, and personal information will only be stored locally on your device and will not be collected. Some features may require access to Internet (e.g. weather) and Quanto Ult only sends requests to these platforms or websites based on your locally stored settings and we do not collect information from them.
